# Jito Solana : vue d ensemble

Jito Solana est une distribution du client Solana intégrant des optimisations pour le marché de la valeur extractible par les validateurs. Le dépôt organise le client, les programmes et les outils nécessaires à un réseau à haut débit.

Le parcours documentaire suit les choix qui relient exécution des blocs, relais et incitations. Les références restent celles du code amont consulté.
