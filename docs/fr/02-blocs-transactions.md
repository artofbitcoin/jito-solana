# Blocs, transactions et exécution

Le client traite les transactions dans une chaîne de bancs et applique les règles de consensus de Solana. Les structures de bloc transportent les signatures, les comptes lus ou écrits et les instructions à exécuter.

Les chemins rapides du client réduisent le coût de propagation et d exécution, tandis que la validation conserve les contrôles de cohérence.
