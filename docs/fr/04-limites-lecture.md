# Limites et lecture du dépôt

Ce dépôt documente un client réseau et ses composants de production de blocs, pas une interface DApp autonome. Les risques principaux concernent la complexité du client, la compatibilité avec les versions Solana et la gouvernance des incitations MEV.

Le parcours couvre uniquement les mécanismes visibles dans les sources et README consultés. Aucune installation, compilation ou exécution n a été réalisée ; les tests présents dans le dépôt constituent la suite de vérification pour une étude ultérieure.
